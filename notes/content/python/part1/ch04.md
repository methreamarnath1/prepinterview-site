# Chapter 4 — Built-in Data Types & the Type System

## 4.1 Numbers: `int`, `float`, `complex`, `bool`

### Definition
> Python has four built-in numeric types: `int` for whole numbers of any size, `float` for decimal numbers, `complex` for numbers with a real and imaginary part, and `bool` for `True`/`False`, which is technically a subtype of `int`.

### Easy Meaning
Whole numbers, decimal numbers, and a special True/False type that's secretly just numbers underneath.

### Remember It
**`bool` is just `int` in disguise — `True` is `1`, `False` is `0`.**

### Simple Example
```python
i = 10
f = 3.14
c = 2 + 3j
b = True
print(isinstance(True, int))   # True
print(True + True)              # 2
```

### Common Mistakes
- Forgetting Python integers have no fixed size limit (unlike many other languages), so there's no integer overflow.
- Assuming floats are always exact — `0.1 + 0.2 != 0.3` due to binary floating-point representation.

### Interview Question
**Q: Is `bool` really a type of `int` in Python?**

### Short Interview Answer
"Yes. `bool` is actually a subclass of `int` in Python. `True` behaves like `1` and `False` behaves like `0` — you can even use them directly in arithmetic, like `True + True` equals `2`."

### Predict the Output
```python
print(0.1 + 0.2 == 0.3)
```
**Answer:** `False`
**Explanation:** Floating-point numbers are stored in binary, and 0.1 and 0.2 can't be represented exactly in binary — so their sum has a tiny rounding error, making it not exactly equal to 0.3.
**Interview Concept Tested:** Awareness of floating-point precision limitations (a hardware-level fact, not a Python bug).

## 4.2 Type Conversion & Truthy/Falsy Values

### Definition
> Type conversion (casting) means converting a value from one type to another, using functions like `int()`, `float()`, `str()`, `bool()`, `list()`. Truthy/falsy refers to how Python treats values as `True` or `False` in a boolean context, like an `if` statement, even if they aren't actual booleans.

### Easy Meaning
Casting = changing a value's "shape" (like turning `"5"` into `5`). Truthy/falsy = every value in Python secretly acts like `True` or `False` when you test it in an `if`.

### Remember It
**Falsy: `False`, `None`, `0`, `0.0`, `""`, `[]`, `{}`, `()`, `set()`. Everything else is truthy.**

### Simple Example
```python
print(bool(""))         # False
print(bool("False"))     # True  -- non-empty string is always truthy!
print(int("42"))          # 42
print(int(3.9))            # 3 -- truncates, doesn't round
```

### Common Mistakes
- Assuming `bool("False")` is `False` — it's actually `True`, because it's a non-empty string.
- Trying `int("3.5")` directly — raises `ValueError`; must go through `float()` first.

### Interview Question
**Q: What values are considered "falsy" in Python?**

### Short Interview Answer
"Falsy values include `False`, `None`, `0`, `0.0`, empty strings, empty lists, empty dictionaries, empty tuples, and empty sets. Everything else is considered truthy, including non-empty strings like `'False'`, which can trip people up."

### Common Interview Trap
**Wrong thinking:** "If a string contains the word 'False', it will be falsy in an `if` check."
**Correct thinking:** Only an *empty* string is falsy. A non-empty string, no matter what it contains, is always truthy.
**What to say in the interview:** "Truthiness is based on whether the container is empty, not its content — so `bool('False')` is actually `True`."
