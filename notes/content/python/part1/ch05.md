## 5.1 Division, Floor Division, and Modulo

### Definition
> `/` performs true division and always returns a float. `//` performs floor division, rounding the result down toward negative infinity. `%` returns the remainder, and its sign follows the divisor.

### Easy Meaning
`/` gives an exact decimal answer. `//` gives the "rounded-down whole number" answer. `%` gives what's "left over."

### Remember It
**`//` always rounds DOWN (toward negative infinity), not toward zero.**

### Simple Example
```python
print(7 / 2)      # 3.5
print(7 // 2)      # 3
print(-7 // 2)       # -4  -- NOT -3!
print(-7 % 2)          # 1  -- sign follows the divisor
```

### Common Interview Trap
**Wrong thinking:** "Floor division just truncates the decimal part, like in C."
**Correct thinking:** Floor division rounds toward negative infinity, which is different from truncating toward zero for negative numbers.
**What to say in the interview:** "`-7 // 2` gives `-4`, not `-3`, because Python's floor division always rounds down, not toward zero."

### Interview Question
**Q: What's the difference between `/` and `//` in Python?**

### Short Interview Answer
"`/` is true division and always returns a float, even if the numbers divide evenly. `//` is floor division — it divides and then rounds down to the nearest whole number, which is important to remember with negative numbers, since it rounds toward negative infinity, not toward zero."

## 5.2 Operator Precedence & `and`/`or` Short-Circuiting

### Definition
> Operator precedence determines the order in which parts of an expression are evaluated. `and` and `or` use short-circuit evaluation, meaning they stop evaluating as soon as the result is determined, and they return one of the actual operand values, not necessarily `True`/`False`.

### Easy Meaning
Precedence = which operation happens first. Short-circuit = Python stops checking further conditions once it already knows the answer.

### Remember It
**`**` is right-associative. `and`/`or` return operands, not booleans.**

### Simple Example
```python
print(2 ** 3 ** 2)     # 512, because ** is right-associative: 2 ** (3 ** 2)
print(0 or "default")   # "default"
print("" and "x")         # ""
```

### Interview Question
**Q: What does `x = a or default_value` actually do?**

### Short Interview Answer
"`or` returns the first truthy value it finds, or the last value if none are truthy. So this pattern is a common way to provide a fallback — if `a` is falsy (like `None` or an empty string), `x` becomes `default_value`; otherwise `x` becomes `a`."

### Predict the Output
```python
print(2 ** 3 ** 2)
```
**Answer:** `512`
**Explanation:** `**` is right-associative, so it evaluates as `2 ** (3 ** 2)` = `2 ** 9` = `512`, not `(2 ** 3) ** 2` = `64`.
**Interview Concept Tested:** Associativity rules beyond simple left-to-right assumptions.
