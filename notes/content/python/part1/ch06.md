# Chapter 6 — Input/Output & String Formatting

## 6.1 f-strings and Format Specifiers

### Definition
> An f-string is a string literal prefixed with `f` that lets you embed Python expressions directly inside `{}` braces, and it's evaluated at the moment the string is created.

### Easy Meaning
f-strings let you drop variables and expressions straight into a string without messy concatenation.

### Remember It
**f-strings are evaluated once, at creation time — not lazily.**

### Simple Example
```python
name, age = "Ana", 30
print(f"{name} is {age} years old")
print(f"{3.14159:.2f}")   # 3.14
```

### Interview Question
**Q: Why are f-strings preferred over `%` formatting or `.format()`?**

### Short Interview Answer
"f-strings are more readable because the variable is written directly inside the string, they're generally faster than `.format()`, and they support inline expressions, including a debug shortcut like `{expr=}` that prints both the expression and its value."

### Predict the Output
```python
x = 5
s = f"{x}"
x = 10
print(s)
```
**Answer:** `"5"`
**Explanation:** The f-string's value is computed and fixed at the moment it's created — changing `x` afterward doesn't retroactively update `s`.
**Interview Concept Tested:** Understanding that f-strings are not lazily evaluated templates.
