# Chapter 7 — Control Flow

## 7.1 `for...else` and `while...else`

### Definition
> The `else` block attached to a `for` or `while` loop runs only if the loop finishes normally, without hitting a `break` statement.

### Easy Meaning
The `else` here doesn't mean "if the loop didn't run" — it means "if the loop never got interrupted by `break`."

### Remember It
**Loop `else` runs unless `break` fired.**

### Why is it used?
It's a clean way to express "search and report if not found," without needing an extra flag variable.

### Simple Example
```python
def is_prime(n):
    for i in range(2, n):
        if n % i == 0:
            print(f"{n} has factor {i}")
            break
    else:
        print(f"{n} is prime")

is_prime(7)   # "7 is prime"
is_prime(8)   # "8 has factor 2"
```

### Common Interview Trap
**Wrong thinking:** "The `else` runs only if the loop body never executed at all."
**Correct thinking:** It runs whenever `break` was never triggered — including cases where the loop ran fully to completion, or the iterable was empty.
**What to say in the interview:** "I'd explain that the `else` block pairs with `break` — it's really saying 'else, if we never broke out.'"

### Interview Question
**Q: When does the `else` clause of a `for` loop execute?**

### Short Interview Answer
"It executes when the loop completes normally, without hitting a `break` statement. If `break` runs at any point, the `else` block is skipped. It's commonly used in search patterns, like looking for an item and reporting 'not found' only if the search never found a match."

### Predict the Output
```python
for i in []:
    print("in loop")
else:
    print("else ran")
```
**Answer:** `else ran`
**Explanation:** The loop body never ran (empty iterable), but no `break` occurred either, so `else` still executes.
**Interview Concept Tested:** Whether the candidate confuses "loop didn't run" with "loop didn't break."
