## 12.1 Lambda Functions

### Definition
> A lambda is a small, anonymous (unnamed) function defined in a single expression, typically used where a short function is needed temporarily.

### Easy Meaning
A lambda is a quick, throwaway function you write in one line, without giving it a formal name.

### Remember It
**Lambda = `lambda arguments: expression` — one expression, automatically returned.**

### Simple Example
```python
square = lambda x: x ** 2
print(square(5))   # 25
```

### Common Mistakes
- Trying to put multiple statements or `print` calls inside a lambda — lambdas can only contain a single expression.
- Overusing lambdas for complex logic, hurting readability — a regular `def` function is often clearer.

### Interview Question
**Q: What's the difference between a lambda and a regular function?**

### Short Interview Answer
"A lambda is an anonymous function limited to a single expression, which it automatically returns — it can't contain multiple statements or a name of its own unless assigned to a variable. A regular function, defined with `def`, can contain multiple statements, has a proper name, and is generally used for anything more than a very simple, short-lived operation."

## 12.2 `map`, `filter`, `reduce`, `zip`, `enumerate`, `sorted`

### Definition
> `map()` applies a function to every item in an iterable. `filter()` keeps only items where a function returns `True`. `reduce()` (from `functools`) combines all items into a single value by repeatedly applying a function. `zip()` pairs up items from multiple iterables. `enumerate()` pairs each item with its index. `sorted()` returns a new sorted list from any iterable.

### Easy Meaning
These are Python's toolbox for transforming, filtering, combining, and ordering collections without writing manual loops.

### Remember It
**map = transform each. filter = keep matching. reduce = combine into one. zip = pair up. enumerate = add index. sorted = new sorted list.**

### Simple Example
```python
from functools import reduce

nums = [1, 2, 3, 4, 5]
print(list(map(lambda x: x * 2, nums)))         # [2, 4, 6, 8, 10]
print(list(filter(lambda x: x % 2 == 0, nums)))  # [2, 4]
print(reduce(lambda acc, x: acc + x, nums))        # 15
print(list(zip([1,2], ['a','b'])))                   # [(1, 'a'), (2, 'b')]
print(list(enumerate(['a','b'])))                      # [(0, 'a'), (1, 'b')]
print(sorted(nums, reverse=True))                        # [5, 4, 3, 2, 1]
```

### Important Differences: `sort()` vs `sorted()`

| Aspect | `list.sort()` | `sorted()` |
|---|---|---|
| Works on | Lists only | Any iterable |
| Returns | `None` (mutates in place) | A new list |
| Original data | Modified | Untouched |

### Interview Question
**Q: What's the difference between `map()`/`filter()` and a list comprehension?**

### Short Interview Answer
"They accomplish similar goals, but `map()` and `filter()` return lazy iterator objects and take a function as an argument, while list comprehensions build the result eagerly and are often considered more Pythonic and readable for simple transformations. In practice, both are common — comprehensions tend to be preferred when the logic is simple, and `map`/`filter` can be useful when you already have an existing function to apply."

### Common Interview Trap
**Wrong thinking:** "`map()` and `filter()` return lists directly in Python 3."
**Correct thinking:** In Python 3, they return lazy iterator objects (`map` and `filter` objects) — you need to wrap them in `list()` to see the results as a list.
**What to say in the interview:** "I'd mention that this changed from Python 2 to 3 — in Python 3, `map` and `filter` are lazy, so you need `list(map(...))` if you want an actual list back."

## 12.3 The `operator` Module

### Definition
> The `operator` module provides function versions of Python's built-in operators (like `+`, `<`, `==`), which is useful when you need to pass an operator as a function, such as to `sorted()`, `map()`, or `reduce()`.

### Simple Example
```python
from operator import itemgetter, add

people = [("Ana", 30), ("Bob", 25)]
print(sorted(people, key=itemgetter(1)))   # sort by age

print(add(3, 4))   # 7 -- same as 3 + 4
```

### Interview Question
**Q: Why would you use `operator.itemgetter` instead of a lambda for sorting?**

### Short Interview Answer
"`operator.itemgetter` does the same job as a lambda that extracts a value from a tuple or list, but it's implemented in C, so it's generally faster, and it's also slightly more readable once you're familiar with it."
