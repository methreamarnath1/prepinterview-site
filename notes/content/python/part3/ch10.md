# Chapter 10: Pattern Matching & Assignment Expressions

### 10.1 `match` Statement (Structural Pattern Matching, Python 3.10+)

**Definition:** `match`/`case` lets you compare a value against a series of patterns — not just literal values, but structures like tuples, lists, dicts, and class instances, with optional destructuring.

```python
def handle(command):
    match command.split():
        case ["go", direction]:
            return f"Moving {direction}"
        case ["look"]:
            return "Looking around"
        case ["take", *items]:
            return f"Taking: {', '.join(items)}"
        case _:
            return "Unknown command"

print(handle("go north"))       # "Moving north"
print(handle("take sword shield"))  # "Taking: sword, shield"
```

### 10.2 Matching Types and Classes
```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

def describe(point):
    match point:
        case Point(x=0, y=0):
            return "Origin"
        case Point(x=0, y=y):
            return f"On Y-axis at {y}"
        case Point(x=x, y=0):
            return f"On X-axis at {x}"
        case Point():
            return "Somewhere else"
        case _:
            return "Not a point"
```

### 10.3 Guard Clauses
```python
def categorize(n):
    match n:
        case x if x < 0:
            return "negative"
        case 0:
            return "zero"
        case x if x % 2 == 0:
            return "positive even"
        case _:
            return "positive odd"
```

### 10.4 Common Mistakes
- Treating `case _:` as optional — without a catch-all, an unmatched value falls through silently (no error), which can hide bugs.
- Confusing `match` with a `switch` statement from other languages — Python's version does structural destructuring, which is more powerful (and different) from simple value comparison.
- Forgetting that a bare name in a pattern (like `case direction:`) **binds** a variable rather than comparing to an existing variable — to compare against an existing variable's value, you must use a dotted/qualified name or a guard.

```python
direction = "north"
match "south":
    case direction:   # This BINDS "south" to direction, it does NOT compare!
        print("matched")
print(direction)   # "south" — overwritten! Common trap.
```

### 10.5 Interview Question
**Q: How is Python's `match` statement different from a traditional switch statement?**

**Short Interview Answer:** "Python's `match` statement supports structural pattern matching, meaning it can destructure sequences, mappings, and class instances, not just compare simple values like a traditional switch. It also supports guard clauses with `if`, wildcard patterns with `_`, and can bind variables directly from the matched structure. One important trap is that a bare variable name in a case pattern acts as a binding, not a comparison against an existing variable's value."

### 10.6 Assignment Expressions (the Walrus Operator `:=`)

**Definition:** The walrus operator lets you assign a value to a variable **as part of an expression**, instead of requiring a separate statement.

```python
# Without walrus:
data = get_data()
if data:
    process(data)

# With walrus:
if (data := get_data()):
    process(data)
```

**Realistic Example — avoiding repeated computation in a loop:**
```python
while (chunk := file.read(1024)):
    process(chunk)
```

**Common Mistake:** Overusing the walrus operator in places where it hurts readability, or misplacing parentheses — `:=` has lower precedence than most operators, so parentheses are often required.

### 10.7 Predict the Output
```python
values = [1, 2, 3, 4, 5]
result = [y for x in values if (y := x * 2) > 5]
print(result)
```
**Answer:** `[6, 8, 10]`
**Explanation:** The walrus operator computes `y = x * 2` inside the filter condition, and that same computed value is reused in the output expression — avoiding recomputation.
**Interview Concept Tested:** Using `:=` to both filter and reuse a computed value in a single comprehension.

### Quick Revision
- `match`/`case`: structural pattern matching — supports sequences, mappings, classes, guards, wildcards.
- Trap: a bare name in a `case` pattern binds, it doesn't compare.
- `:=` (walrus): assignment as part of an expression — useful in `while`/`if`/comprehensions to avoid recomputation.
