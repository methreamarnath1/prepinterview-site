# Chapter 4: Virtual Environments & Dependency Management

### 4.1 Why Virtual Environments?

**Definition:** A virtual environment is an isolated Python installation with its own site-packages directory, so dependencies for one project don't conflict with another.

```bash
python -m venv myenv
source myenv/bin/activate      # Linux/Mac
myenv\Scripts\activate          # Windows

pip install requests
pip freeze > requirements.txt
pip install -r requirements.txt
deactivate
```

**Interview Q: Why do we use virtual environments instead of installing packages globally?**
**Answer:** "Different projects often need different, sometimes conflicting, versions of the same package. Installing everything globally means only one version can exist system-wide, which breaks projects that need older versions. A virtual environment isolates each project's dependencies, so version conflicts between projects never happen, and it also makes deployments reproducible via `requirements.txt`."

### 4.2 `pip` Essentials
```bash
pip install package_name
pip install package_name==1.2.3     # pin exact version
pip install "package_name>=1.0,<2.0"  # version range
pip uninstall package_name
pip list
pip show package_name
```

### 4.3 `requirements.txt`
```text
requests==2.31.0
flask>=2.0,<3.0
numpy
```
**Best Practice:** Pin exact versions for production deployments (reproducibility); allow ranges for libraries meant to be installed alongside other packages (avoids overly strict conflicts).

### 4.4 Common Mistakes
- Installing packages globally without a virtual environment — leads to "works on my machine" bugs.
- Forgetting to activate the virtual environment before installing — packages silently go to the global environment instead.
- Committing the `venv/` folder to version control instead of just `requirements.txt` — bloats the repo and isn't portable across OSes.

### Quick Revision
- `venv` isolates dependencies per project.
- `pip freeze > requirements.txt` captures exact installed versions.
- Pin versions for reproducibility in production.
