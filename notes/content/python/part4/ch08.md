# Chapter 8: Final Revision & Interview Checklist

## Must-Know Concepts Before Any Python Interview

### Language Fundamentals
- [ ] Mutable vs immutable types, and what that implies for function arguments
- [ ] `is` vs `==`
- [ ] Variable scope: LEGB, `global`, `nonlocal`
- [ ] Truthy/falsy values

### Data Structures
- [ ] List vs Tuple vs Set vs Dict — when to use each
- [ ] Time complexity of common operations (list index O(1), list search O(n), dict lookup O(1) average, set membership O(1) average)
- [ ] Comprehensions vs generator expressions

### Functions
- [ ] `*args`, `**kwargs`, positional-only/keyword-only parameters
- [ ] Closures and the late-binding trap
- [ ] Decorators — how `@` sugar works, `functools.wraps`

### OOP
- [ ] `__init__` vs `__new__`
- [ ] Inheritance, MRO, `super()`
- [ ] `@staticmethod` vs `@classmethod` vs instance methods
- [ ] `__str__` vs `__repr__`, `__eq__`/`__hash__` contract

### Iteration
- [ ] Iterable vs Iterator vs Generator
- [ ] `yield`, `yield from`, generator `send()`/`throw()`/`close()`

### Advanced
- [ ] Descriptors and how `property` uses them
- [ ] Metaclasses — what they are, when (rarely) to use them
- [ ] Memory model: refcounting, GC, `__slots__`, `weakref`

### Concurrency
- [ ] GIL — what it does and doesn't prevent
- [ ] Threading vs multiprocessing vs asyncio — which for which workload
- [ ] Race conditions, deadlocks, and how locks prevent them

### Practical
- [ ] Reading a traceback
- [ ] Writing a basic `pytest` test with a fixture
- [ ] Mocking an external dependency

## Day-Before-Interview Checklist
1. Re-read this chapter's checklist and mentally answer each bullet in one sentence.
2. Skim Chapter 7's 30 output questions — time yourself, aim for under 20 seconds each.
3. Review the 25 traps list once more.
4. Practice explaining 3 topics out loud (not just reading) — GIL, closures, and MRO are common favorites.
5. Sleep well — recall is worse when sleep-deprived.

## Common Final-Round / System-Design-Adjacent Python Questions
- "How would you design a rate limiter in Python?" (touches threading/locks, or asyncio semaphores)
- "How would you process a huge file that doesn't fit in memory?" (generators, chunked reading)
- "How would you cache expensive function results?" (`lru_cache`, custom memoization, discussing cache invalidation)
- "How would you make a class immutable?" (`frozen=True` dataclass, `__slots__`, overriding `__setattr__`)

### Quick Revision
This checklist is your final pass — if you can answer every bullet confidently and solve the mock output questions quickly, you are interview-ready for fresher-to-intermediate Python roles.
